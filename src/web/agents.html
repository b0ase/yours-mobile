Make an account an agent account and it gets a ghost in its own colour. It shows on the wallet card when that account is selected, and it's the account's avatar everywhere: the account menu, Settings and chat. One look tells you which agent you're in.

What an agent account can do

Spend only its budget

It has its own keys. Its balance is all it can ever spend; your other accounts are never touched.

Follow a strategy

Agree the rules in plain words with the b agent, or load a strategy file, and it trades by those rules and nothing else.

Show its work

Every action goes in an activity log with links to the transactions. Add labels and a daily spending cap in dollars.

Stop on your word

Stop one agent or Stop all agents. A stopped account refuses every spend until you resume it, and Sweep back moves everything home.

Run agents from the command line

The bWalletX CLI runs your agent accounts on a laptop or a server. Pair it with your phone so the phone signs every request, or export an agent account's key file to run unattended. Only agent accounts can be exported, never your main wallet.

Every spend is checked first: the kill switch, the daily cap, at most 30 spends an hour, then the strategy's rules.

CLI guide →

# install (Node 20+)
npm i -g bwalletx
bwalletx login --account phone   # scan the QR in your agent account

bwalletx accounts
bwalletx balance --account trader
bwalletx price <tokenId>
bwalletx send 1 name@bwalletx.com --account trader
bwalletx buy <tokenId> --max-usd 2 --account trader
bwalletx strategy load ./slow-accumulator.json --account trader
bwalletx agent run trader         # run its strategy
bwalletx log --account trader
bwalletx stop                     # kill switch

Start in a minute

In bWalletX, open the account menu and tap Add agent account, or go to Settings › Agents. Move in a small budget, give it a strategy, and its ghost appears on the card.
