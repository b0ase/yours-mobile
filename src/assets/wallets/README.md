# Wallet and chain marks

Used only on Settings › Linked wallets to name the wallet a user is linking (nominative use). The marks are
trademarks of their owners; they are not recoloured or redrawn. Each SVG was reduced to paths, shapes and
gradients (no scripts, event handlers, external links, foreignObject or images) and minified.

| File           | Mark              | Source                                                                                                                                               |
| -------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `metamask.svg` | MetaMask fox      | MetaMask Logo Pack, linked from https://metamask.io/assets (`MetaMask/MetaMask-icon-fox.svg`). github.com/MetaMask/brand-resources now points there. |
| `phantom.svg`  | Phantom app icon  | Phantom press kit, linked as "Press Kit" in the footer of https://phantom.com (`Phantom App Icon/phantom-app-icon-drkprpl.svg`)                      |
| `tronlink.png` | TronLink app mark | https://www.tronlink.org/favicon.ico (93px PNG), resized to 64px and stripped of metadata. TronLink publishes no SVG of its current mark.            |
| `tron.svg`     | TRON chain mark   | https://tron.network/favicon.svg                                                                                                                     |

Ethereum, BNB Chain and Solana badges use `react-icons/si`.
