# bMint port plan: bcorp-mint into bWalletX Desktop (/bmint)

Scoping only. Source: `/Volumes/2026/Projects/bcorp-mint` (Electron, electron-vite, v0.2.1). Target: `/Volumes/2026/Projects/bwalletX` (branch `bwallet`), `src/mobile`, wide shell `VITE_WIDE_WEB=1`, routes in `src/mobile/tabs/MobileRoutes.tsx`.

Main finding: bcorp-mint already has a **platform-neutral `shared/` layer** (`shared/lib/platform.ts` with a `FileHandle` path|File union and `PlatformFeature` flags; `shared/hooks/useMintDesigner.ts`; `shared/lib/mint-patterns.ts`, `mint-defaults.ts`, `render.ts`, `qr-encoder.ts`). That layer was built for the browser site (`website/`, bitcoin-mint.com). The `shared/` designer, pattern and render code imports nothing outside itself and nothing from Node, so it can be copied in largely as is. The Electron-only parts (`src/main/*`) are the ones we drop or replace with the wallet.

Minting rule: bMint never builds a key, WIF or broadcaster of its own. Every on-chain write goes through `src/mobile/mint/mint.ts` (NFT inscriptions, with `kind: 'picture'` and extra MAP fields such as `bmint: 'note' | 'ticket' | 'stamp'`, `template`, `serial`) or `names/opnsMint.ts` (names, owned by the other agent). Any new helper takes the wallet the same way `mint.ts` does. Design files are rendered to PNG in the browser and passed in as a `File`.

## 3. Assets, licences, bundle

- **Copy**: `src/renderer/assets/logos/mint-*.svg` (drop `npgx-*` unless wanted), template art in `public/bcorp notes landscape/image-1..11.jpg` (re-encode to WebP at ≤1600px: expect about 2 MB down to about 400 KB total), and `public/bg-guilloche.jpg`, `bg-rosette.jpg`, `bg-banknote-wide.jpg` for landing tiles. **Do not copy** the 23 MB `public/` wholesale; the MP4s and screenshots are marketing for the website.
- **Fonts**: Space Grotesk, IBM Plex Mono, Oswald, Bebas Neue, Permanent Marker and Bangers, all SIL OFL from Google Fonts. The canvas needs them loaded before `fillText`. Self-host the woff2 files under the lazy chunk's assets (the store build and CSP prefer no Google Fonts call), and use `document.fonts.load()` before rendering.
- **Licence**: bcorp-mint has **no LICENSE file** and is `private`, copyright The Bitcoin Corporation. Same owner, so the code can be relicensed into bWalletX under MIT ([[client-licence]]). The owner should confirm (Q1). `react-pageflip` is MIT. Drop `js-1sat-ord`, `@bsv/btms`, `@bsv/message-box-client` and `ffmpeg-static`. `@b0ase/creator-tool-core` (a `link:` dependency) must not be pulled in; check whether `shared/` imports it (it appeared only in the Electron package deps).
- **Bundle**: the whole section is `React.lazy(() => import('./bmint/BmintPage'))`. Each sub-route is lazy as well (the designer chunk with patterns, fonts and templates is about 150–250 KB min+gz, and tokenise with react-pageflip comes later). The main bundle grows by roughly 1 KB. Gate the route on `VITE_WIDE_WEB` if the mobile shell should not show it; the code is responsive anyway.

## 4. Store-edition gating (`src/mobile/storeBuild.ts`)

Add, in the same style (a literal env check so Rollup drops the code):

```ts
/** bMint currency-like notes (Banknote/Coin templates, "denomination" layers): never in a store build. */
export const BMINT_NOTES_ENABLED: boolean = !( /* same three literal checks as CURVE_COINS_ENABLED */ );
```

- Store build: `/bmint` shows Tickets (art only), Logo, QR, Stamp (hash proof) and OpNS. **Notes/Coin templates are hidden**, and the lazy import sits behind `BMINT_NOTES_ENABLED` so it is never in the bundle. A designed "banknote", even when minted as an NFT, reads to reviewers as issuing currency (Apple 3.1.5 / Play financial services).
- `bcorpFeeAddress()` already zeroes Mint fees in a store build. Any bMint fee must use it.
- Ticket art can be minted; ticket-gated room access stays under `STORE_HIDDEN_WALLET_KINDS`.
- Tests: extend `storeBuild.test.ts` for both values of the flag.
